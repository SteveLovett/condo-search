# condo-search

A one-page list of 1–2 bedroom condos for sale under $500K in Carlsbad, Encinitas, and San Marcos, CA (Redfin listings as of Oct 13, 2026), with an estimated monthly cost for each.

Live page: https://stevelovett.github.io/condo-search/

Income, down payment, and debt figures aren't stored in this repo. They go in the page link after the `#`, which browsers don't send to the server.
